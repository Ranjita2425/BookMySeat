# Online Movie Ticket Booking System

A responsive Django-based online movie ticket booking system with secure authentication, seat selection, and booking management.

## Features

- User registration and login
- Movie listing and details
- Showtime selection
- Interactive seat selection
- Available, Reserved, Booked, and Selected seat status
- Online ticket booking
- Booking history
- Responsive design for desktop, tablet, and mobile devices
- Django admin management

## Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- Vercel
- Git & GitHub

## Installation

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
